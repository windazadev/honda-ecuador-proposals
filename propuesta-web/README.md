# Propuesta web — Bento corporativo Honda Ecuador

Prototipo responsive de alta fidelidad construido únicamente a partir de la auditoría UX/UI aprobada, los manuales de marca y los recursos locales de Honda.

## Dirección creativa

- Hero bento basado en una columna editorial de texto y tres módulos de acceso.
- Autos ocupa el módulo principal; Motos y Productos de fuerza equilibran la segunda fila.
- Cada módulo completo funciona como enlace y comunica su destino de forma explícita.
- Retícula asimétrica, esquinas rectas y ausencia de sombras o efectos de plantilla.
- Entrada institucional sobria, construida con fotografía auténtica y recursos locales.
- Sin tipografía sobredimensionada, recursos decorativos futuristas, gradientes o composiciones tipo presentación.
- La innovación se concentra en la interacción y la claridad de navegación.
- Honda Red `#CC0000`, blanco, negro y Poppins como bases del sistema.

## Principios aplicados

- Las tres líneas de negocio aparecen de forma permanente y en el mismo orden.
- La navegación principal prioriza Autos, Motos y Productos de fuerza.
- No se utiliza slider ni se repiten accesos de contacto o test drive.
- Cada destino funciona como enlace completo, con CTA explícito, respuesta visual y foco visible.
- El fondo general es claro y Honda Red se utiliza como acento principal.
- La experiencia funciona con teclado y respeta `prefers-reduced-motion`.
- Los tres destinos del prototipo son páginas locales funcionales; deben sustituirse por las URL finales durante la integración.

## Vista local

Abrir `index.html` directamente o servir la carpeta con un servidor local.
